## Publicación
Sube todos los archivos a la raíz del repositorio de GitHub Pages:
- index.html
- styles.css
- manifest.webmanifest
- sw.js
- logo-192.png
- logo-512.png
- favicon.png

GitHub Pages debe usar la rama `main` y la carpeta `/ (root)`.
